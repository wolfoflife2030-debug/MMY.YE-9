# MMY.YE — برنامج لوحة التحكم (ويندوز + أندرويد)

نفس الموقع (`www/index.html`) مُغلَّف كبرنامج:
- **ويندوز**: Electron → ملف تثبيت `.exe` + نسخة محمولة.
- **أندرويد**: Capacitor → ملف `.apk`.

## البناء التلقائي (الأسهل)
1. ارفع المجلد إلى مستودع GitHub.
2. من تبويب **Actions** اختر **Build Windows + Android** ثم **Run workflow**.
3. بعد انتهاء البناء نزّل الملفات من **Artifacts** (`MMY-Windows` و `MMY-Android`).
4. للنشر كإصدار: `git tag v1.0.0 && git push origin v1.0.0` فتظهر الملفات في **Releases**.

## البناء على جهازك (ويندوز)
```
npm install
npm start          # تشغيل تجريبي
npm run dist:win   # يخرج ملف التثبيت في dist/
```

## الأيقونات
`assets/windows-icon.png` و `assets/android-logo.png` هما الأصل؛ الأيقونات الجاهزة (خلفية بيضاء + حواف دائرية) في `build/`.
لإعادة توليدها: `python3 scripts/make_icons.py assets/windows-icon.png assets/android-logo.png build`

## الأرشيف السنوي (يُدار بالكامل من داخل البرنامج)
من **لوحة التحكم ← الأرشيف السنوي** أو من أيقونة الأرشيف في الشريط الجانبي. تبويب **الأرشيف السنوي** صفحة واحدة: اختر السنة، راجع النتائج (الحجم والأشخاص والدروس مقابل الأهداف + المهام والصيانة والعهد والمواد) وقائمة كل الأقسام التي ستُحفظ، ثم زر واحد «أرشفة السنة» (مع خيار إزالة السجلات من النظام الحي). بعده:
1. **إقفال سنة**: يُنشئ الأرشيف ويفحص سلامته ويحفظه **داخل البرنامج**، ثم يفتحه مباشرة للتصفح. لا حاجة لأي ملف ZIP.
2. **التصفح**: ملخص السنة، كل قسم في جدول مع بحث، والضغط على أي سجل يعرض تفاصيله كاملة، وللمواد الأرشيفية تُعرض **الملفات المرفقة** (معاينة الصور والفيديو والصوت داخل البرنامج، وحفظ/مشاركة لأي ملف).
3. **التحكم**: استرجاع سجل واحد أو قسم أو السنة كلها إلى النظام الحي (مع المرفقات)، إزالة السجلات المؤرشفة من النظام الحي بعد تأكيدك، فحص السلامة، حذف أرشيف سنة.
4. **ZIP اختياري**: «نسخة خارجية (ZIP)» و«استيراد سنة من ملف خارجي» للاحتياط أو النقل لجهاز آخر فقط.

المؤرشف سنوياً: المهام (المنتهية/الملغاة)، الصيانة (المكتملة)، العهد (المُعادة)، سجلات التقييم، المواد الأرشيفية. أما المراكز والكادر والمعدات والجاهزية فتُحفظ منها لقطة ولا تُحذف.
السنة تُحدَّد بالتاريخ داخل السجل، وإلا بسنة الإنشاء. السجلات القديمة قبل التفعيل تُنسب لـ«سنة السجلات القديمة».
> الأرشيف مخزّن داخل البرنامج (IndexedDB)، لذلك يدخل ضمن **النسخة الاحتياطية الكاملة** (انظر أدناه). احفظ نسخة خارج الجهاز بانتظام.

## النسخ الاحتياطي
- **نسخة احتياطية كاملة (ZIP)**: البيانات + الملفات المرفقة + الشعارات + كل السنوات المؤرشفة. **نسخة خفيفة (JSON)**: البيانات فقط.
- **أندرويد**: عند الحفظ تظهر نافذة: **حفظ مباشر** (يفتح اختيار المكان: فلاشة USB عبر OTG / بطاقة SD / ذاكرة الهاتف / Drive) أو **مشاركة** (واتساب، بريد ...). يعتمد الحفظ المباشر على مكوّن `SaveAs` (`scripts/android/SaveAsPlugin.java`) الذي يضيفه الـ workflow تلقائياً عبر `scripts/android_saveas.sh`.
- **ويندوز**: نافذة «حفظ باسم» لاختيار أي قرص أو فلاشة (`electron/preload.js`).
- **الاستيراد** يقبل النسخة الكاملة والخفيفة؛ استعادة الكاملة تستبدل البيانات والمرفقات والأرشيف.

## البصمة على أندرويد
- تستخدم واجهة البصمة الأصلية للنظام (مكوّن `@capgo/capacitor-native-biometric`) لأن WebView لا يدعم WebAuthn.
- **تُطلب تلقائياً عند كل فتح للبرنامج**، وعند العودة إليه بعد غياب أكثر من دقيقة. كلمة المرور تبقى متاحة دائماً.
- تُفعَّل افتراضياً إذا كان في الجهاز بصمة أو قفل شاشة، ويمكن إيقافها من الإعدادات.
- على ويندوز تبقى Windows Hello (WebAuthn) كما هي، وتُطلب تلقائياً أيضاً إذا سُجّل الجهاز.
- يضيف الـ workflow صلاحية `USE_BIOMETRIC` تلقائياً عبر `scripts/android_biometric.sh`.
- **إصلاح v1.3**: كانت مكوّنات أندرويد تُثبَّت بخيار `--no-save` فلا يكتشفها Capacitor عند `cap sync`؛ صارت تُثبَّت في package.json (`--save-dev`) ويطبع الـ workflow قائمة الإضافات المكتشفة (`cap ls`) للتأكد. وإذا فشلت البصمة تظهر الآن رسالة بالسبب الحقيقي بدل رسالة عامة. يُقبل قفل الشاشة (PIN/نمط) كبديل إذا لم تكن هناك بصمة مسجّلة.
- **مهم**: يجب إعادة بناء الـ APK من الـ workflow (ومن ثم تثبيته) لتعمل البصمة والحفظ المباشر؛ تعديل ملف HTML وحده لا يكفي.

## شاشة البداية
عند تشغيل التطبيق على أندرويد تظهر شاشة بداية بشعار البرنامج (على خلفية داكنة) بدل شعار Capacitor الافتراضي. تُولَّد الصور في `build/android-splash/` ويطبّقها `scripts/android_splash.sh` تلقائياً في الـ workflow. لتغيير الشعار حدّث `build/logo-512.png` وأعد توليد الصور.

## ملاحظات
- البيانات تُحفظ محليًا داخل البرنامج (نفس سلوك الموقع)؛ صدّر نسخة احتياطية من الإعدادات بانتظام.
- اسم المستخدم الافتراضي `admin` وكلمة المرور `1234` وسيطلب البرنامج تغييرها.
- ملف APK الناتج من `assembleDebug` للتجربة؛ للنشر في Google Play يلزم توقيع Release.
